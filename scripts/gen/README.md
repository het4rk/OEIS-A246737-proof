# Generators

Python/SymPy scripts used to generate the large Lean files (types, step, linear forms). They were run from `/workspace/oeis-6`; paths inside are absolute. `gen_even2.py` writes the even-k forms and `split_even.py` splits them into `EvenBase`/`EvenChain*`/`FormsEven`. They are not needed to build or check the proof.
